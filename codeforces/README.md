# codeforces

Solutions organized by contest type, round number, and problem letter.

## Structure

```
<contest-type>/
  round-<NNN>/
    <letter>/
      solution.<ext>
```

## Contest Types

- `div1/` — Codeforces Round, Division 1
- `div2/` — Codeforces Round, Division 2
- `div3/` — Codeforces Round, Division 3
- `div4/` — Codeforces Round, Division 4
- `educational/` — Educational Codeforces Round
- `global/` — Codeforces Global Round

Problem letters run A (easiest) → F/G (hardest) within each round.

Indexed in code.db at [krisyotam.com/code](https://krisyotam.com/code/codeforces).
