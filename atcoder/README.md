# atcoder

Solutions organized by contest series, number, and problem letter.

## Structure

```
<series>/
  <NNN>/
    <letter>/
      solution.<ext>
```

## Contest Series

- `abc/` — AtCoder Beginner Contest (easiest)
- `arc/` — AtCoder Regular Contest
- `agc/` — AtCoder Grand Contest
- `ahc/` — AtCoder Heuristic Contest

Problem letters run A (easiest) → F/G (hardest) within each contest.

Indexed in code.db at [krisyotam.com/code](https://krisyotam.com/code/atcoder).
