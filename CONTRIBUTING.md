# Contributing

Contributions should keep each platform's existing taxonomy intact. Read the
README inside the relevant platform directory before adding a solution.

## Adding a solution

1. Put the solution under the appropriate platform directory.
2. Follow that platform's directory and filename convention.
3. Prefer one solution file per language attempted.
4. Include the problem URL in a short source comment when the language permits.
5. Do not copy the full problem statement, examples, editorial, or other
   platform-owned material into this repository.
6. Run the solution against the platform's published examples before committing.

Use focused commits. A commit should normally add or improve one solution, or
make one clearly described repository-wide maintenance change.

## Repository maintenance

- Keep generated binaries, caches, credentials, and local editor files out of
  Git.
- Do not rename established problem paths without also updating incoming links.
- Changes to the root structure should update the platform table in `README.md`.
