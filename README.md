# euler

Project Euler solutions organized by problem number and slug.

## Structure

```
<NNN>-<slug>/
  solution.<ext>       one file per language attempted
```

Problem numbers are zero-padded to 3 digits (e.g. `001-multiples-of-3-or-5`).

Indexed in code.db at [krisyotam.com/code](https://krisyotam.com/code/euler).
