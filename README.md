# cp

Competitive-programming solutions collected in one monorepo and organized by
platform, contest, and problem.

## Platforms

| Directory | Platform | Organization |
| --- | --- | --- |
| [`atcoder/`](atcoder/README.md) | AtCoder | contest series, contest number, problem letter |
| [`codeforces/`](codeforces/README.md) | Codeforces | division or series, round, problem letter |
| [`codewars/`](codewars/README.md) | Codewars | kyu, kata slug |
| [`euler/`](euler/README.md) | Project Euler | problem number and slug |
| [`hackerrank/`](hackerrank/README.md) | HackerRank | domain, subdomain, challenge slug |
| [`leetcode/`](leetcode/README.md) | LeetCode | topic, problem number and slug |

Each directory retains the history and taxonomy README from its former
standalone repository. New solutions belong here; the former repositories are
read-only migration sources.
