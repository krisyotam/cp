# cp

Competitive programming solutions organized by platform and problem.

## Structure

```
leetcode/
hackerrank/
codewars/
codeforces/
atcoder/
euler/
```

Each platform directory contains solutions organized by topic, difficulty, or contest. File naming follows the convention `problem-slug.ext` or `problem-number.ext`.

## Adding a solution

Drop the file in the appropriate platform directory. Use subdirectories for contest rounds or topic groupings when they make sense.
